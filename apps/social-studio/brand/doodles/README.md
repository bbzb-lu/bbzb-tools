# Doodles

- Herkunft: Doodle Icons von Khushmeen, https://khushmeen.com/icons (Zip «doodle icons», SVG).
- Lizenz: CC0, kein Hinweis nötig. Der Link unter der Liste ist ein Wunsch von Alexej.
- Ausgelassen: Kategorie «files». Alle anderen 14 Kategorien (auch «logos») sind drin, 427 Doodles.
- `doodles.json` erzeugt `node scripts/build-doodles.mjs "<entpackt>/doodle icons/SVG"`: nur schwarze Pfade, Zahlen auf 1 Nachkommastelle. Zip und Quell-SVG nicht einchecken.
