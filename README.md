# BBZB Tools

Websuite, die Abläufe am BBZB Luzern einfacher macht. Die Tools laufen im Browser, nichts wird hochgeladen und der Code ist offen.

```
npm install
npm run dev:startseite
```

Hinweise für Mitarbeit und Agenten stehen in [AGENTS.md](AGENTS.md).

Für das Social Studio: `npm run fonts` holt Braveold aus dem privaten Repo (Zugriff nötig).
